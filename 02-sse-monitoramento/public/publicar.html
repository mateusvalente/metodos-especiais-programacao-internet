O que este botão faz?

  1. 1. Navegador Envia um POST /api/notifications para o Node. Esta página não é um cliente MQTT.
  2. 2. Node Transforma o CPF em tópico e chama broker.publish(...) .
  3. 3. Mosquitto Entrega a publicação aos clientes que fizeram subscribe .
  4. 4. Painel Recebe um evento SSE somente se acompanhar o mesmo CPF.

Tópico da próxima publicação: lab/cpf/00000000000/notificacoes

Fluxo: formulário → POST no Node → tópico lab/cpf/{cpf}/notificacoes → Mosquitto → Node → SSE → painel.
