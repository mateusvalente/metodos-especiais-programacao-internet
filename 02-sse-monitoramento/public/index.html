    O caminho de uma notificação

    1. 1. HTTP POST A página de envio entrega CPF e mensagem ao Node.
    2. 2. PUBLISH O Node publica no tópico lab/cpf/00000000000/notificacoes .
    3. 3. Mosquitto O broker distribui a mensagem para quem assinou o tópico.
    4. 4. SUBSCRIBE O Node assina lab/cpf/+/notificacoes ; + aceita um CPF por vez.
    5. 5. SSE O Node filtra pelo CPF acompanhado e escreve um evento alert na conexão HTTP aberta.

    Último tópico recebido nesta página: aguardando

    Ao trocar o CPF, o navegador abre outro EventSource . O SUBSCRIBE MQTT do Node continua o mesmo.

    No DevTools → Network, observe a requisição /events aberta e os eventos reading e alert . O envio acontece em outra página, via HTTP → MQTT → Mosquitto → Node → SSE.
